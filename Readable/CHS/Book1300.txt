<title name = 大型臻冰雕塑特展将在至冬堡举办/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_03/>
<center>《大型臻冰雕塑特展将在至冬堡举办》</center>
（本报讯）仰赖皇都评议会对人民文化生活的关切及向来正确的决策，一场大型臻冰雕塑艺术特展将在未来于至冬堡隆重举办。本次特展的主题为《经典再冻结：冰星果派大师作品（复刻）特展》，该主题由评议会与臻冰艺术联盟共同敲定，旨在为广大市民朋友、广大人民，以及广大心向至冬文化的爱好者们提供领略大师艺术、深入了解至冬文化传统的机会。

本次特展不仅是十年难遇的艺术盛会，更是标志着臻冰艺术进一步走向人民的重要事件。臻冰艺术联盟的代理主席库斯托季耶夫女士向本报表示：臻冰雕塑制造成本高昂，过去曾是独属于宫廷的赏玩，在苍星王廷的时代，有诗句记录着当年的情况：「臻冰雕塑一尊尊送往王公的府邸，炉灰区的矿工喝不上一碗红甜菜汤。」这正是对历史的真实写照。

库斯托季耶夫女士还表示：自女皇陛下登基以来，至冬便沐浴于她的仁爱之中，如今，任何艺术都不再是王公贵族的专属。然而，臻冰雕塑的特殊性，使其注定难以走进家家户户。本次举办特展的决议，足可见评议会对女皇陛下的仁爱之追随，也足可见他们对至冬人民的牵挂与一视同仁。
皇都评议会方面则指出：一场具有历史与文化特色的艺术展无疑能够凝聚人心，唤醒人们为至冬荣光而奋斗的热忱。因此，在这风雪交加的时日，举办这样的特展有好处，也有必要。

目前，评议会尚未公布艺术展的具体举办日期。不过本报了解到，艺术展的展品订单已经下派到彩冰镇，镇上一位名为马列维奇的臻冰设计师在接受记者采访时表示，他为能接到本次艺术展的订单无比骄傲——只因他是万千普通至冬人中的一个。

<title name = 《怪语奇谭》本期投稿：公爵的自白/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_09/>
<center>《怪语奇谭》本期投稿：《公爵的自白》</center>
诸位，我乃特罗欣公爵，我的亲眷们…我美丽优雅的妻子，我数不胜数的仆从们，都死于那场火灾…而我，作为唯一的幸存者，只能苟延残喘，在此书写纵火者的罪孽。

「凡怀异心者，应即毫不犹豫，从所有隐匿之处曳出，一一勘定，然后以必要之各种相当手段，加以歼除，此令。」

纵火者索林执行了压迫者的命令，以最为严苛的手段覆灭了我的家族。他们在火中悲鸣，「噼里啪啦」的声音是乐曲，扭曲如焦炭的肢体是痛苦的舞姿——这让我想起了我们的最后一次聚会…

怀念啊…那晚，压迫着我们的主人公已沉沉睡去，暗沉的夜幕下，我点亮狂欢的明灯。所有人舞啊…唱啊…全然不顾自己因压迫而僵硬的身躯…

然后…然后我们就迎来了流放——因为我们纵情于舞会，不再忠实，不再匍匐。在华丽的牢笼里，我们相互体贴，共同憎恨着压迫者，而在流放的土地上，大雨落下，我们开始互相指责——那才是真正烧死我们的大火，有些叛徒，他们甚至在怀念压迫者，怀念他所给予的少量甜头。

直到火舌舔舐着我的四肢时，我才恍然发觉，我差点被烧死了！凭什么？就因为我不愿再用我这可怜的脊梁，去体贴地承托诸位高高在上的臀部吗？

好了，如今，幸存者仅我一个，我不便再组织反抗的舞会…我只是个独活的可怜公爵，我能怎么办呢？我只好用我的余生，来缅怀那个大家齐舞的夜晚了。
