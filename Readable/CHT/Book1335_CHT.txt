<title name = 假扮運輸局警探查詢「鑑定細節」？釀酒廠員工切勿受騙！/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_08/>
<center>《假扮運輸局警探查詢「鑑定細節」？釀酒廠員工切勿受騙！》</center>
本報訊，近日，至冬皇家軌道運輸局繳獲了一批私酒作坊仿製的「假火水」，順「假水火」的銷售通路，成功打擊了三處製造、運輸、販賣劣質酒水的非法工坊，收繳摩拉一千萬餘。

「假火水」一直是至冬官方的主要打擊對象，只是這次「假火水」仿製得十分到位，儘管酒液本身品質堪憂，可是不管是裝酒的瓶身細節，酒瓶瓶蓋或是瓶身標籤的防偽印刷處都與真品別無二致。

經過調查，原來是私酒作坊的犯罪集團在仿製之前，偽造證件假扮運輸局警探，以搜查鑑定偽劣產品為由，詢問商家「鑑定細節」，商家為了配合官方調查，不僅提供了防偽設計，還提供了瓶身樣品，私酒作坊以此仿製了「假火水」的酒瓶與包裝。

再次提醒，運輸局的警探並不會因各種原因要求商家提供防偽設計細節、討要樣品、預付摩拉或是提供如何迴避至冬法律條款的付費諮詢，謹記保護好一切敏感資訊。

<title name = 從窗戶跳進雪堆刺激又有趣？可能導致嚴重後果…/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_02/>
<center>《從窗戶跳進雪堆刺激又有趣？可能導致嚴重後果…》</center>
隨著氣溫進一步下降，連續幾日的降雪量也達到了歷史記載的高點，為了清理出通行的道路，街道清理人員會將街道清理出的雪暫時堆在居民區建築外牆下。

有孩童和心智與孩童相仿的至冬居民抓住這樣的機會，開始了一項危險的遊戲——即從高處的窗戶直接躍入窗戶下的雪堆中。此舉或許能夠帶來一時的快樂，卻也容易產生一系列的糾紛，甚至已令多人不慎受傷。

根據本報記者調查，在短短數日內就已發生三起因「跳下雪堆」產生的糾紛了。

居住在爐灰區的女童A某，在跳下雪堆時才發現雪堆下居然有人放置了臻冰發射臺，以至於被彈射向了街道另一側的屋頂，受困數小時後才被接到報告的運輸局員工解救下來。

居住在爐灰區的少年B某，在跳下雪堆後發現雪堆下的是前一日因為醉酒而跌入雪堆的妖精C某，導致C某的手臂受到了嚴重傷害。

居住在極星區的男士D某，在跳下雪堆後，驚醒了雪堆中前一日因為醉酒而跌入雪堆的妖精E某，幸運的是，跳躍的落點在E某周圍，未使後者遭受如前一個事件中C某所受的重傷。不幸的是，因此被激怒驚醒的妖精E某下意識重擊了D某，令D某手臂受到了嚴重傷害。

本報提醒，追求刺激與有趣是個人選擇，但也不能忽視過程中的安全隱患與可能對他人造成的困擾。

<title name = 臻冰展品失竊後被追回，展會負責人盛讚「行動力超群」！/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_09/>
<center>《臻冰展品失竊後被追回，展會負責人盛讚「行動力超群」！》</center>
本報訊，於採冰鎮舉辦的臻冰雕像展覽「經典再凍結：冰星果派大師作品（復刻）特展」正在如火如荼地舉辦中。

但在此期間，發生了冰星果派大師作品的復刻品遭人竊取，甚至企圖盜往至冬國外的事件。好在至冬皇家軌道運輸局的警探及時發現，在竊取者即將出境前予以逮捕，緝拿歸案，遭竊的臻冰展品也成功物歸原主。

展覽的主辦方也對此表示感謝：

「呃…非常感謝運輸局的警探們，雖然…呃，畢竟是復刻特展，被竊取的也都是不太值錢的復刻品，而且處理起來蠻麻煩，所以本來就打算在展覽結束後抽選贈送…所以就算被竊取了，也不會感到困擾…」

「但…總之還是感謝運輸局，這個辦事效率的確是滿高的。」

法網恢恢，疏而不漏，至冬皇家軌道運輸局警探的高效行動向大家證明了即使是出境後過不了多久就會融化的臻冰造物，運輸局也會在融化之前追回！
