<title name = 《怪語奇譚》本期投稿：奧古洛夫詭談/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_10/>
<center>《怪語奇譚》本期投稿：《奧古洛夫詭談》</center>
大家都知道，毛毛蟲在樹葉裡做繭，就會變成不祥的飛蛾，爛泥裡有青蛙的種子，後來長出了腳，才變成可以跳、可以游的青蛙。古老的妖精傳說中，還認為人死後埋在地下，血肉腐爛了，脊椎骨就會變成一條蛇。

生命的起始，總與生命的完成形態有所不同。但唯有一隻鳥，從出生之後都是同一個樣子了。

風景清麗的山谷深處，住著一隻美麗得讓人移不開眼睛的火鳥。牠張開翅膀可以遮蔽天空，眼睛像寶石，羽毛像金子，只要見到牠的人，就會跟隨牠步入山谷的深處，成為牠鍾愛的食糧。

當然，火鳥並不喜愛啄食腥臭的血肉，牠喜食人的記憶。

記憶是寬敞的宮殿，是靈魂的居所。沒有記憶，人就不能稱之為人。被火鳥吞食「記憶」後，人便會失去感官、情感與語言，退化成無知覺的樹木，團團圍繞這座山谷中的小鎮，遮擋外來者的視線。而火鳥只需靜靜地等待，等待下一個好奇的來客靠近。

當然，時間會在火鳥身上留下衰老的痕跡，利器也會在牠身上留下傷痕，死亡並不會遠離這隻美麗的火鳥，但是新的生機會眷顧牠。當清風吹拂，已然無用的軀殼開始在陽光下泛起溫熱，來自「生」的火焰點燃火鳥絢麗的羽葉，牠在滾燙的烈火中拍打雙翼，落於空中的灰燼中滋養出新的血肉。最終，火鳥會再次披上華麗的盛裝，盤旋於奧古洛夫鎮上空，靜靜凝視著每一個被牠的美麗所吸引的過客。

（所以，筆者傾情建議各位讀者，珍愛生命，遠離奧古洛夫鎮，畢竟大家不能像火鳥一樣，一遍又一遍地重生嘛！）

<title name = 警惕保險騙局，守護摩拉安全/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_04/>
<center>《警惕保險騙局，守護摩拉安全》</center>
「投保時信誓旦旦，理賠時一分沒有」？近日，關於至冬保險陷阱的傳聞甚囂塵上，經過深入調查後，本報記者發現系列案件都與名為「幸福至冬保險公司」的機構有關。

去年，一位蒙德旅客在該公司投保，為自己的臻冰魚竿購買了「臻冰造物融化險」。保險內容為若是受保製品融化，受益人將獲得最高20萬摩拉。該名旅客隨後返回蒙德垂釣，魚竿融化。旅客向保險公司索賠，保險公司卻聲稱：「該保險明確有『須證明受保製品在至冬境內融化』的條款，因此不能予以賠償。」

無獨有偶，一位至冬堡市民也於近期在該公司的保險產品上遇到理賠問題。這位不具名的市民表示，自己本是一個藝術演出愛好者，但近年至冬堡戲劇演出品質良莠不齊，為此她購買了該公司推出的「觀劇創傷修復險」。然而，當她真的因為觀賞了一部糟糕劇作導致三天喝不下最愛的冰醋栗原漿，遂前去該公司尋求理賠時，保險公司卻表示該保險的理賠條件是受保人須證明自己真的因為觀劇受到了精神創傷，而該受保人既然能自行前來申請理賠，就證明她精神正常。

目前，至冬堡方面已經對該公司立案調查。同時，運輸局提醒廣大至冬群眾務必擦亮雙眼，謹防保險陷阱，守護摩拉安全。另，若要購買列車延誤險，請選擇運輸局官方推出的保險產品，保障好自己的權益。

<title name = 《雪國熱議》本期投稿：歷史重影說/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_09/>
<center>《雪國熱議》本期投稿：《歷史重影說》</center>
提瓦特新編年史·至冬篇（其五）
歷史重影——虛構還是科學？

在先前的連載中，筆者曾提出如下判斷：主流史學界篤信的偽史與至冬的信史，兩者之間存在顯著的相似。其程度之高，已經不足以再用單純的文化接觸或傳說流轉來解釋。

筆者開創性地將此現象總結為「歷史重影」：表面上來自不同區域、不同時代的文字紀錄，實際上是同一歷史在不同視角下的反覆改寫——這段被掩蓋的歷史就是莫諾馬赫皇帝的征服史。

在莫諾馬赫皇帝統治時期，全提瓦特的大部分區域實際上都處於同一個沙皇國的統治下。

筆者曾翻閱過冒險家協會的報告，如今的諸國皆存在建築風格相對統一的——與我們在至冬見到的遺蹟風格相近的——古代遺蹟。這是不可辯駁的事實。而這個統一的文明，很明顯就是莫諾馬赫皇帝的國度。
