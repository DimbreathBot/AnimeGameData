<title name = 『怪語奇譚』今号の投稿：星海と悪夢の狭間で、フィオードル氏の時空を超越した精神の旅/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_09/>
<center>『怪語奇譚』今号の投稿：『星海と悪夢の狭間で、フィオードル氏の時空を超越した精神の旅』</center>
フィオードル氏は冒険者協会に所属する博物学者であり、寡黙で人付き合いが得意ではないものの、常人離れした博識さと鋭い知性で同僚たちから高く評価されている。どれほど経験豊富なベテラン冒険者でも、あらゆることに精通した彼の知識量には舌を巻くほどである。
しかし、そんな博識な専門家が、ほんの五年前まで無職で大酒飲みの中年男性だったということは、フィオードルの妻だけが知る事実だ。夫がなぜ一夜にしてこれほど大きく変わったのか、妻は疑問に思いつつも心から喜んでいた。少なくとも、夫のことで夜も眠れぬほど悩むようなこともなくなると。
だが、その年の夏のある日、フィオードル氏は冒険者たちに講義をしている最中に突然気を失ってしまった。目を覚ますと、彼は知識に関する質問に答えられなくなっていただけでなく、自分が博物学者であったことなど一切覚えていなかった。
彼の語るところによれば、この五年間、彼は長い悪夢に囚われていた。夢の中で彼は「記録者」と名乗る異星の種族に出会い、彼らによって魂を数多くの奇妙な星々へと連れて行かれた。そして最後に、爬虫類やトカゲたちに支配されていたテイワットにたどり着いてようやく、自分が史書に記録されたことのない太古の時代にやって来たのだと知ったという。これら異星の種族の要求により、彼は自身の五年間にわたる見聞を筆記に書き記し、トカゲたちの城に残してきたのだそうだ。
その後、フィオードル氏は療養所に送られて治療を受けた。医者たちは彼が何らかの精神疾患を患っただけだと主張し、フィオードル自身も次第に彼らの見解を受け入れ、すべてはただの悪夢に過ぎなかったのだと信じ込むようになった。
ところが先月、かつてフィオードルに師事した冒険者たちから極秘の手紙が届いた。彼らはナタのとある遺跡の奥深くで、フィオードルが語ったという特殊な石板でできた古代の手記を掘り当てたという。
さて、話はここまでだ。フィオードルの悪夢は、永遠に終わらないのかもしれない。だが、もう一つ恐ろしい疑問がある。今夜あなたの隣で眠るその人の体に宿っているのは、本当にあなたの記憶にある「その人」と同じ魂なのだろうか？

<title name = 千年にわたり伝承されし古の知恵！/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_07/>
<center>『千年にわたり伝承されし古の知恵！』</center>
最新の研究によると、温かいお湯に浸かるのはやめたほうが健康にいいとのことだ。
スネージナヤ伝統医学発展促進会の最新研究成果によれば、クルースニクの炉が発明される以前、スネージナヤ人は温かいお湯での入浴を一切行っていなかったという。そしてこれこそ、私たちの先祖が歴史上で常に長寿であった理由とされている。
研究によると、温かいお風呂は体を温め、皮膚の毛穴を広げてしまう。毛穴が開いてしまうと、空気中の有毒な瘴気が毛穴から体内に入りやすく、様々な病気を引き起こすこととなる。また、温かいお湯によって体の表層に自然に形成される菌群の防護網が破壊され、人体の免疫機能が低下する。
スネージナヤ伝統医学発展促進会より市民の皆様へ、まずはあなたから入浴の習慣を改めよう！

<title name = アンナ・ペトロヴァ女史による厳粛なる声明/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_08/>
<center>『アンナ・ペトロヴァ女史による厳粛なる声明』</center>
私は本日をもってミハイル・ペトロフ氏と正式に別居することを宣言するとともに、同氏を法律上の夫として認めることを拒否します。
ミハイル・ペトロフ氏はスネージナヤ伝統医学発展促進会なる団体が発表した、熱いお風呂を否定する荒唐無稽な研究について読んで以来、それを盲信し、三ヶ月もの間いかなる形での入浴も拒否し続け、申し訳程度にタオルで体を拭く程度で済ませてしまっています。現在、その体からは沼地のような悪臭が漂っており、私にはとても耐えられるものではございません。
身の安全を考慮し、私はミハイル・ペトロフ氏の住居を離れました。以後、同氏の言動は私と一切無関係であることをここに表明いたします。
