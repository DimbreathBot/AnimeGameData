<title name = 《怪語奇譚》本期投稿：風雪中的無頭列車員/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_05/>
<center>《怪語奇譚》本期投稿：《風雪中的無頭列車員》</center>
馬蒙托夫來稿

這是從朋友的朋友那裡聽來的故事。

過去的安德烈做夢也想不到自己會淪落到一無所有，在列車上當司爐工，只為向幫派討一條活路，慢慢還清欠款。他在新基捷城原本有著體面的營生，但現在店鋪被強行抵押，未婚妻也理所當然地解除了和他的婚約，甚至就連家人也拒絕對他伸出援手，將他掃地出門。

一切的罪魁禍首，是那種他不該碰的「遊戲」。一開始，他真的以為自己受了好運的垂青，能在牌桌上賺得口袋滿滿的，但他哪裡懂得贏永遠只是暫時的，輸才是最終的結果。
他原本還將翻盤的指望寄託在老友茲拉諾夫身上——茲拉諾夫曾神神秘秘地許諾，說在挪德卡萊藏著能夠一次結清他們所有債務的秘密，只要安德烈再投資他最後一次——可是，茲拉諾夫一去不返，再也沒有關於他的任何消息，安德烈最後的希望也就這麼破滅了。
司爐工的薪水若是放在從前，他只會不屑一顧。但現在，這就是他的全部了。只是這樣一點點還債，要到哪一天才能重見天日？與其把錢還給幫派填那深不見底的窟窿，不如留做本錢，再去牌桌上搏一把…就算違約幾次，幫派也不至於下什麼狠手。但每當這個念頭升起，過去傾家蕩產被掃地出門的恐懼就會讓他退縮。在猶豫與煎熬中，日子就隨著汽笛聲一天天消磨。

直到某天夜裡，列車在狂風怒雪中艱難前行，車頭燈費力地在黑暗與雪幕中鑿開一條狹窄的光道。就在這僅有的視野之中，毫無徵兆地出現了一個如同幽靈般的影子。一個衣衫襤褸的人，手裡提著一盞燈，在軌道旁踉蹌地走著。
在這種呼吸都能被凍住的鬼天氣裡，除非是耐寒的妖精，普通人根本撐不過半個鐘頭。安德烈出於本能的憐憫，想提醒列車長減速救人，卻發現對方臉色煞白地盯著窗外。安德烈順著他的視線望去，這才發現那個在風雪中蹣跚的身影肩膀上空空如也，而在本該長著頭顱的地方，竟然詭異地燃燒著一團沒有溫度的火焰。
列車沒有絲毫減速，像是生怕驚擾了那個無頭人，沒有鳴笛，只是掠過他，將那團火焰拋在無邊的黑夜裡。

在那之後，驚魂未定的列車長才說起了原本已被遺忘的舊聞。
那是從前在這條線上工作的一個叫老卡什青的人，此人沒什麼大毛病，無非就是嗜酒如命，對金錢毫無概念。眾所皆知，他欠了幫派一筆還不清的爛帳，但他本人卻對此毫不在意。反正幫派還指望他工作還錢，也不能拿他怎麼樣，他是這樣打算的，於是大夥也就隨他去了。
直到有一次，列車正行進在這條荒涼的路線上，有乘客報告說車頂有異常動靜，懷疑是此前遭遇的風仙匪徒留下的破壞。老卡什青很不情願地被派上車頂去檢查。

誰也不知道他上去之後看到了什麼。只聽到車頂傳來噹啷一聲悶響，接著，老卡什青那顆帶著驚愕表情的頭顱，就那麼順著車窗玻璃滾落到了雪地裡，很快被黑暗和風雪吞沒了。
那根本不是普通的襲擊，而是處刑。那兩個幫派的匪徒在列車的必經之路上從兩側拉起了一根纖細但卻無比堅韌的索線，以此結果了老卡什青的性命。

「這是他欠『伊茲梅洛』的。」
那兩個匪徒敲敲車窗，留下這句話就飛走了。

而從那之後，老卡什青就成了這條路線上永久的囚徒。他無法安息，只能提著那盞破燈在風雪中徘徊，漫無目的地尋找他再也還不清的債，以及他丟失的頭顱…

<title name = 關於鐵路沿線異狀的聲明/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_04/>
<center>《關於鐵路沿線異狀的聲明》</center>
據本報報導，近日，在至冬堡至凝露鎮鐵路沿線的凍原上，有罕見魔物出沒的痕跡。種種跡象表明，這些魔物是從南部邊地流竄而來的，並且，令人扼腕的是其中一隻狂獵手中攥著那盞已損壞的提燈曾經屬於某位執燈人。這無疑是一則令人悲痛的消息，某位可敬的執燈人顯然已遭逢不幸。
值得慶幸的是運輸局已聯絡駐守皮拉米達城的執燈人部隊，雙方果斷聯手，徹底清剿凍原上徘徊的魔物。
運輸局特此懇請諸位市民，若在鐵路沿線發現任何類似異狀，請務必保持冷靜，切勿驚慌，即時向運輸局回報。相關部門將會迅速應對，盡快排除風險，為市民朋友的安全外出保駕護航。

<title name = 《雪國熱議》本期投稿：阿赫瑪爾偽王考/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_09/>
<center>《雪國熱議》本期投稿：《阿赫瑪爾偽王考》</center>
提瓦特新編年史·須彌篇（其三）
虛構的沙漠史——從阿赫瑪爾的虛假性說起

在先前的連載中，筆者曾提出如下判斷：迭卡拉庇安、阿赫瑪爾、雷穆斯、奧奇坎，這幾位所謂的統治者均非實際存在的歷史人物，而是同一歷史原型——也就是莫諾馬赫皇帝——在不同地區留下的傳說變體。

只要稍作研究，我們便不難發現上述幾位虛構的統治者皆滿足如下特徵：

其一、被後世的歷史學者視為暴君（這是因為他們不願承認莫諾馬赫皇帝曾經征服、統治過全世界）。

其二、遺體並未留存於世（這是因為莫諾馬赫陛下的遺體安眠於白冕宮，他們無法篡改這項事實）。

其三、與他們相關的所謂「歷史遺蹟」皆為後世偽造（這是因為他們的文明史很短，所以必須要杜撰偽史）。

以主流史學界所篤信的須彌沙漠史為例，其中就存在諸多經不起推敲的疑點：

首先，吃什麼？

眾所皆知，須彌沙漠是——如字面所示——沙漠。別說幾千年前，就是今天的沙漠，也不可能養得活那麼多人，又怎麼可能修建起恢宏的赤王陵呢？

再來，拿什麼修赤王陵？

雖然筆者沒去過須彌，但沙漠地區明顯不存在大規模的採石場遺蹟，而已知的運輸手段均無法長距離運輸如此巨量的石材。

那麼，真相便呼之欲出了——那就是所謂的「赤王陵」其實是莫諾馬赫皇帝修建的。後來的沙漠人誤讀了皇帝的名字，先是把「莫諾」和「馬赫」倒了過來變成「馬赫莫諾」，又在口頭轉述中丟掉了句首的子音（這在各語言中很常見），並發生了輕度母音位移，變成了「阿赫馬諾」，最終演變成了今天的「阿赫瑪爾」。

筆者曾在挪德卡萊有幸結識一位來自須彌沙漠的年輕淑女，她向筆者出售了一套傳說中由阿赫瑪爾親自鍛造的護符。事後經確認發現，這些護符上面用楓丹的文字刻著「千靈映影節專用」。那位美麗而優雅的淑女當然不會騙人，這只能代表一件事——那就是須彌的歷史其實是楓丹偽造的。

此外，那位淑女還提供了一個相當重要的佐證——她說她的族人都將阿赫瑪爾稱作「戀愛之神」。眾所皆知，在那個時代，被稱作「慈愛之神」的只有一位，那就是莫諾馬赫皇帝…
