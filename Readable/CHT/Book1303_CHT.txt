<title name = 皇都治安凱歌頻傳！驚擾市民數星期之「浮浪武士」今日伏法！/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_02/>
<center>《皇都治安凱歌頻傳！驚擾市民數週之「浮浪武士」今日伏法！》</center>
本報專訊，近日引發至冬堡市民數星期惶惶不安之稻妻「浮浪武士」已於昨日凌晨時分伏法就擒，籠罩整座城市的恐怖陰霾就此煙消雲散。
數星期以來，在至冬堡下城的多個街區乃至格魯波夫堡外的偏僻小徑內，於深夜頻繁發生惡性事件。目擊者稱歹徒乃是一名身著殘破緋紅具足、頭戴怪異面具的「海亂鬼」。依仗駭人的面容與詭異的刀法，多名受害人未等對方發話，便嚇得拋下財物逃之夭夭。隨著受害人數量增多，一度引發全城百姓之惶惶不安。
所幸在精明強悍之至冬堡警察局長的親自督辦下，警察局所屬的刑偵署與冬契軍巡邏隊通力合作，展開了日夜不停的嚴密偵查。終於在昨日深夜，於下城區一間廢棄的麵包房內發現了該名歹徒的蹤跡。隨後趁歹徒全副武裝準備外出作案的機會，埋伏在四周的精明巡查們果斷出擊，將對方當場制伏！
經查，此名歹徒本係稻妻離島的一名特許商人，因與當地主管的勘定奉行發生了不可調和之利益糾紛，導致其商會於前年徹底破產。此人不甘淪為平民，竟在走投無路之下，私自竊取了供奉於當地神社中的緋紅具足與奉神刀出逃國外。先是流竄至我國邊境之挪德卡萊邊疆區，自稱稻妻武士招搖撞騙，遭秘聞館揭穿之後，又竄入女皇陛下之神聖首都至冬堡，意圖再次行騙。然而在意外發現恃其駭人裝束便可肆行劫掠後，便屢施故技，終於在引發全城恐慌後遭我方抓獲。
由於此嫌係外逃者，稻妻官方拒絕承認其僑民身分，因此等待他的將是至冬法律的審判。此案後續發展如何，還請繼續追蹤本報消息。

<title name = 達爾杜佛的至冬遊記！/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_09/>
<center>《達爾杜佛的至冬遊記！》</center>
（編者註：本文為楓丹作家達爾杜佛於一百三十八年前寫下的至冬遊記，後經證實，達爾杜佛一生都沒有離開過楓丹。）
（又註：為避免讀者因原文的事實謬誤產生誤解，編者已特意標註出文章中不符合至冬現實或者容易引發誤會的表述。）
…我們的大陸上有這樣一個冰雪眷顧的國度，它曾令諸多冒險家神往，但對寒冷的恐懼使他們繞行在邊境線外。於是，這個國度變成一個模糊而巨大的象徵，以至於史學家開始懷疑它根本不存在。我也曾眺望過它，或者繞行，直到最終克服了對神秘的恐懼。我終於看到了它——透過列車的玻璃窗，至冬在那裡。
至冬，這個國度的居民中，沒有一個畏懼嚴寒，只因在無盡風雪覆蓋的土地下，生長著可以燃燒的寶石[1]。人類只是其中一種具有智慧的生命，哪怕是一隻獵犬、一隻高昂著頭顱的貓咪，甚至是你路過的一棵大樹，都有可能在不經意之間口吐古老而文雅的語言[2]。
在這片土地上，人們沒有飲用咖啡的習慣，因為大地上的任何作物都能被釀造成好酒。一位貴族邀請我品嚐了他們一種名為「格瓦斯」的國民飲料，口感與楓達有些微妙的相像。他告訴我，一些至冬堡的王公曾經考慮過前往楓丹廷旅遊居住[3]，但考慮到格瓦斯並不在楓丹販售，便打消了這個念頭。
……
[1]這裡講的應該是晶礦。
[2]這裡是作者對妖精的單方面想像。
[3]這就是無稽之談了。

<title name = 《冰上舞曲》今日來稿：這究竟是什麼樣的演出？/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_01/>
<center>《冰上舞曲》今日來稿：《這究竟是什麼樣的演出？》</center>
最近在至冬堡上演的《海鳥》，是筆者幾十年來所見最糟糕之劇目！依演出呈現而言，它既非能喚醒觀眾崇高悲痛的嚴肅作品，亦非能令人放聲大笑的滑稽喜劇。
觀眾在《海鳥》裡，究竟還能找到些什麼？這部以「先鋒」與「現實」為噱頭的作品，竟只顯示出作者對舞臺技巧毫不嫻熟！英雄乃一部戲應該有之主要人物。而在《海鳥》裡，英雄並不存在。所謂主角，不過是一個怯懦男人，加上一個失敗女人。他們缺乏行動，對命運無比順從，盡是小角色神氣，未有一個能引發演員演出之興致。
另，一部優秀作品所應有之曲折，被《海鳥》全然拋棄。平淡的劇情進展裡，夾雜著漫長停頓，這便是本劇目的結構特徵了。無人為偉大事業犧牲，更無人得到拯救，因此，這劇目自是沒有什麼可談的了，布局和主題，亦是兩句話便能說完。
舞劇一向是至冬之瑰寶，可是《海鳥》卻以「先鋒」為藉口，拋棄了這塊瑰寶的一切優秀傳統。本劇不曾留下動人心魄之故事，只顯現出鬆散的結構、煩惱的小人物，還有無關緊要的蠅蟲。嗚呼，此等作品竟能問世，筆者為此感到萬分痛心！
（撰稿人：特里果林）
