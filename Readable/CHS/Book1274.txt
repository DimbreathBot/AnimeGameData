<title name = 最新天文大发现！月球上的神秘生物？/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_01/>
<center>《最新天文大发现！月球上的神秘生物？》</center>
本报昨日接获来自极北之地（由于相关研究成果尚未发表，出于保密原则，具体位置本报不便透露）天文台的最新消息，著名天文学家伊凡·赫歇列夫博士凭借其新型巨显微望远镜，已成功观测到月球表面之绝景。
新型巨显微望远镜的设计原理来自于赫歇列夫博士的天才构想，他通过将一台高达二十四倍放大的高倍复式显微镜，安置在长度达七十余尺的巨型望远镜的目镜之上，从而创造性地突破了传统光学的极限，并辅以高度精炼的克什尼克晶矿燃起的强光照射，实现了前所未有的超高倍率放大效果。
据悉，军械宫为这一不可思议的项目拨付了资金，但在此前却从未向公众披露，也未将其列入每年的预算报表当中。对此，赫歇列夫博士表示，为在各国之间的科学竞赛中独占鳌头，愚人众方面早已关照参与各方均须严格保密，或许这就是为什么我们直到今天才知晓这一刺破宇宙帷幕的前沿项目的存在。
在赫歇列夫博士委托本报发表的信件中，详细描绘了他所观测到的月球表面的风景，包括森林、河流、山谷与草原，以及生活在月球上的诸多神奇生物：野牛、鲸鱼、水母…甚至还有企鹅！
此外，赫歇列夫博士还特别提到他在月球上发现了疑似智慧生物留下的痕迹——一座由蓝色晶石建造而成的宫殿，其塔楼正指向了我们！建造它的人们想要向我们传达什么样的信息？是想宣告他们文明的辉煌，又或是警告我们未来将要面临的灾祸？
在信件的最后，赫歇列夫博士还提到了一种无法确定其真实身份的类人生物，它长着金色的毛发，背上有一对薄膜翅膀，徘徊在望远镜视野的各处。可惜的是，在拍摄到其样貌前，观测就被迫中止了。原因是赫歇列夫博士在睡前忘记将望远镜降下放平，导致太阳升起后，穿过镜头的阳光经透镜聚焦引发了火灾。所幸在场的工作人员及时处理，未造成人员伤亡。
虽然本次观测由于意外事故被迫中止，但取得的成就已足以震撼科学界。虽有因循守旧的学院派研究员质疑该研究成果“纯属虚构”，但来自教令院明论派的学者们已对这一研究做出了高度的评价，有多名诃般荼‌在读到信中所披露的研究成果时，激动至当场昏厥。
之后本报将分六期刊载赫歇列夫博士委托本报发表的信件全文，请渴望了解月球真相的读者朋友们切勿错过！

<title name = 《怪语奇谭》本期投稿：消失的兽怪矿工/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_09/>
<center>《怪语奇谭》本期投稿：《消失的兽怪矿工》</center>
马蒙托夫来稿

这是从朋友的朋友那里听来的故事。

利斯岑是在运输局工作不到一年的新人，他出身彩冰镇，过去最大的梦想就是离开家乡，到至冬堡或是新基捷城这样的大城市生活。现在他的梦想实现了一半，他作为列车员所负责的线路正是连通新基捷城、至冬堡和彩冰镇三地的。
他凭借着外向健谈的性格，很快和常乘坐这趟列车往来的旅客熟络起来，也从和他们的闲聊中获得了不少可堪解乏的谈资。「契科塔」警探透露的案件内情，雪精讲述的赫斯珀利德斯之馆的传说，诸如此类的消息总能让他在回老家和从未走出家乡的老友叙旧时，态度也高上几分。因此他很喜欢这份工作，动机姑且不论，他确实一度对工作投入了热情，直到让他大病一场的那次事件。

那天对利斯岑来说是再普通不过的一天，车厢里有几个返校学生，讨论新上演剧目的年轻夫妇，高大而忧郁的雪精，一些兽怪矿工…其中不乏他熟悉的面孔。
兽怪矿工颇有些兴奋，据他们说，在新基捷城以西很远的地方挖到了什么不便声张的东西。尽管不便声张，他们还是忍不住向其他人分享了，看来是真的很不得了的物件。「如果是从基捷城的旧址里取了什么，最好尽快归还，否则会遭遇不幸。」听到了他们的对话，忧郁的雪精如此警告。
利斯岑打了个寒颤，好像这话有立竿见影的效果，他检查了列车上的供暖装置，运转正常，但那股异样的寒气却似乎始终萦绕在车厢之中。他有些犹豫，这件事是否应该汇报给上级，好让警探来介入调查。他想当个尽职的列车员，但他不想当一个可耻的告密者。

不过这两难的境地并未让他困扰太久，因为当天晚上他就发起了高烧，这对一向身体健康的他来说是非常罕见的。原因不明的高热让他不得不告病一周，甚至在重返岗位后仍自觉十分虚弱，身体状况大不如前。
据运输局的同僚说，那班列车上的其他乘客也几乎是同一时间病倒了，有些身体孱弱的至今尚未恢复。这位同僚在新基捷城还有位亲戚，有通灵的本事，他特意就这次的事件咨询了那位亲戚的意见，得到的答复是，那几个兽怪矿工受了黑神的诅咒，把不干净的东西带到了列车上，乘客们，还有利斯岑，都是因为邪灵入侵才生了怪病。利斯岑本打算反驳，但想到那天好像蛇一样从脚底爬上来的寒气，到嘴边的话又咽了下去。

再后来，利斯岑再也没见过那几个兽怪矿工，也没有听过他们的消息。或许是工作原因，他们不再乘坐这趟列车，又或许是被触怒的黑神将他们…无论如何，他们的身影，或是存在本身，就像是被冻原上无休止的风雪给抹除了一般，再也寻不到一丝痕迹…

<title name = 关于禁止部分旅客乘车的声明/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_04/>
<center>《关于禁止部分旅客乘车的声明》</center>
据本报讯，近日，运输局公布了最新的禁止乘车旅客名单，引发民众热议。其中，雪精伊·尼·伊瓦诺夫先生因「无任何违规行为却遭禁乘」向运输局提起强烈抗议，认为此举侵犯了其合法权益。
昨日，运输局对此作出了正式答复，揭示了禁令背后的无奈真相。据运输局调查，雪精伊瓦诺夫先生频繁购票乘坐往返至冬堡与新基捷城的列车，实为悼念其过世的恋人——她曾作为列车员在此条线路任职——然而，伊瓦诺夫先生每每在车厢内睹物思人，陷入哀恸时，就会无意识地强化其作为雪精的能力，导致车厢温度骤降，因此而罹患严重风寒的旅客不可计数。
运输局强调，伊瓦诺夫先生本人虽无恶意，但为保障广大旅客的身体健康与出行安全，运输局不得不做出禁止其乘车的决定，希望市民朋友能对此予以体谅和理解。
