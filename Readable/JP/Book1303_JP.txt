<title name = 皇都の治安改善の朗報続々！数週間にわたり市民を脅かした「浮浪武士」、本日ついに逮捕！/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_02/>
<center>『皇都の治安改善の朗報続々！数週間にわたり市民を脅かした「浮浪武士」、本日ついに逮捕！』</center>
本誌特報。最近、スネージナヤ・グラード市民を数週間にわたり不安に陥れていた稲妻の「浮浪武士」事件が昨日未明の犯人逮捕をもって幕を閉じ、街全体を覆っていた恐怖の影は完全に払拭された。
数週間にわたり、スネージナヤ・グラードのダウンタウンの複数街区、さらにはグルポフ外の人気のない小道において、深夜に悪質な事件が頻発していた。目撃者によれば、犯人はぼろぼろの緋色の具足を身に着け、奇妙な仮面を被った「海乱鬼」であったという。その恐ろしい風貌と異様な刀さばきにより、多くの被害者は相手が言葉を発する前に驚いて財物を投げ捨て、逃走したという。被害者の数が増えるにつれ、街中の市民が恐怖と不安に包まれていった。
幸い、優秀なスネージナヤ・グラード警察局長の直接指揮のもと、警察局所属の捜査課と冬契軍パトロール隊の緊密な協力により、昼夜を問わず徹底した捜査が行われた。そしてついに昨晩遅く、ダウンタウンにあるパン屋の廃墟の中で犯人のものと思しき痕跡を発見した。その後、武装して犯行に出ようと外に出た瞬間を狙い、周囲に張り込んでいた優秀な捜査員たちが一斉に踏み込み、その場で取り押さえることに成功した！
調査によると、この犯人はもともと稲妻の離島で営業許可を持つ商人であったが、当地を管理する勘定奉行との間で調停不可能な利益紛争が生じ、一昨年にその商会は完全破産したという。平民に成り下がることが納得できなかった犯人は進退窮まった末、当地の神社に奉納されていた緋色の具足と奉神刀を盗み出し、国外へと逃亡。まず我が国の国境沿いにあるノルドカール辺境区に至り、稲妻の武士を自称して詐欺を働いたが、秘聞の館に正体を暴かれると今度は女皇陛下の神聖なる首都、スネージナヤ・グラードへと潜入し、再び詐欺を働いた。その恐ろしい出で立ちさえあれば堂々と略奪が行えることに意図せず気づいた後は同じ手口を繰り返すようになり、ついには街全体を恐怖に陥れたのち、逮捕されるに至った。
犯人は国外逃亡者であるため、稲妻当局は在外国民としての身分を認めておらず、犯人はスネージナヤの法律のもとで裁判にかけられることとなる。本件の続報については、引き続き本誌からの発表をお待ちいただきたい。

<title name = ダルドフのスネージナヤ旅行記！/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_09/>
<center>『ダルドフのスネージナヤ旅行記！』</center>
（編集者注：本稿はフォンテーヌの作家ダルドフが138年前に記したスネージナヤ旅行記であるが、後に判明したところによれば、ダルドフは生涯フォンテーヌを離れたことがなかったという。）
（追記：原文の誤った事実により読者が誤解を招かないよう、本誌はスネージナヤの実情とまったくそぐわない、あるいは誤解を生じやすい表現に対し注釈を付した。）
…我々の大陸には、氷雪に愛された国がある。かつて多くの冒険者たちを魅了したが、寒さへの恐怖が彼らを国境線の外へと遠ざけた。やがてその国はぼんやりとした巨大な象徴へと変わり、歴史家たちは存在の可能性にすら疑いを持つほどになった。かつての私も、最終的にその神秘に対する恐怖を乗り越えるまでは、その国を遠くから眺めたり、迂回するだけであった。そしてついに私はその姿を目にした——列車の窓ガラス越しに、スネージナヤが視界に入り込んできた。
スネージナヤ——この国の住民には、極寒を恐れる者が一人もいない。それは、止むことのない吹雪に覆われた大地の下に、燃える宝石[1]が眠っているからだ。人間はそこに暮らす知性ある生命のひとつに過ぎず、一匹の猟犬、誇らしげに背筋を伸ばす一匹の猫、あるいは道端の大樹でさえも、ふとした瞬間に古風で優雅な言葉[2]を語り出すことがあるのだ。
この地の人々にはコーヒーを飲む習慣はない。大地に育ついかなる作物からも、醸造して味わい深い酒が作れるからだ。ある貴族が「クワス」と呼ばれる国民的な飲み物を勧めてくれたのだが、その味わいはどこかフォンタと近いものがあった。彼が言うには、スネージナヤ・グラードの王公たちの中にも、かつてフォンテーヌ廷へ旅行や滞在を考えた者がいたそうだ[3]。しかし、クワスがフォンテーヌでは売られていないと知り、その考えを思い留まったのだという。
……
[1]晶鉱のことと思われる。
[2]作者によるフェイへの一方的な想像である。
[3]まったくのでたらめな話である。

<title name = 『氷上の舞曲』本日の投稿：理解しがたい公演内容/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_01/>
<center>『氷上の舞曲』本日の投稿：『理解しがたい公演内容』</center>
最近スネージナヤ・グラードで上演された『海鳥』は、筆者がここ数十年で目にした中で最も酷い演劇だった！その公演の内容と言えば、観客の崇高な悲痛を呼び醒ますシリアスな作品でもなければ、大笑いできるコメディーでもない。
観客は『海鳥』の中に、一体何を見出せるのだろうか？「前衛性」と「リアル」を売り文句にしたこの作品は、制作者が舞台における技巧にまったく習熟していないことをさらけ出しただけではないか！英雄とは、一つの演目に欠かせない主要人物である。しかし『海鳥』には、英雄が存在しない。いわゆる主人公と言えば、臆病な男性と負け組の女性に過ぎない。彼らには行動力がなく、運命に対してただ従順であり、端役のような振る舞いばかりで、演者の演劇意欲を掻き立てられる人物など一人もいないのだ。
また、優れた作品が備えるべき場面の起伏も『海鳥』には全く見られない。単調な展開の中に長い間が挟まるだけ、それがこの演劇の構造的特性であった。偉大な事業のために身を捧げる者もいなければ、救われる者もいない。ゆえにこの演劇には語るべきことが何もなく、構成とテーマもたったの二言で言い尽くせてしまう。
バレエはスネージナヤの至宝と言えるが、『海鳥』は「前衛性」を言い訳にその至宝のあらゆる優れた伝統を捨て去った。心を揺さぶる物語を残すことなく、ばらばらの構成、悩める小物の登場人物、そして取るに足らない羽虫どもを晒すばかり。ああ、このような作品が世に出てしまうとは、筆者は心より痛恨の念を覚える！
（寄稿者：トリグリン）
