<title name = 皇都治安凯歌频传！惊扰市民数周之「浮浪武士」今日伏法！/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_02/>
<center>《皇都治安凯歌频传！惊扰市民数周之「浮浪武士」今日伏法！》</center>
本报专讯，近日引发至冬堡市民数周惶惶不安之稻妻「浮浪武士」已于昨日凌晨时分伏法就擒，笼罩整座城市的恐怖阴霾就此烟消云散。
数周以来，在至冬堡下城的多个街区，乃至格鲁波夫堡外的偏僻小径内，于深夜频繁发生恶性事件。目击者称，歹徒乃是一名身着残破绯红具足、头戴怪异面具的「海乱鬼」。依仗其骇人的面容与诡异的刀法，多名受害人未等其发话，便吓得抛下财物逃之夭夭。随着受害人数量的增多，一度引发全城百姓之惶惶不安。
幸而，在精明强干之至冬堡警察局长的亲自督办下，警察局所属的刑侦署与冬契军巡逻队通力合作，展开了日夜不停的严密侦查。终于在昨日深夜，于下城区一间废弃的面包房内发现了该名歹徒的踪迹。随后趁其全副武装准备外出作案的机会，埋伏在四周的精明巡查们果断出击，将其当场制服！
经查，该犯本系稻妻离岛的一名特许商人，因与当地主管的勘定奉行发生了不可调和之利益纠纷，导致其商会于前年彻底破产。该犯不甘沦为平民，竟在走投无路之下，私自窃取了供奉于当地神社中的绯红具足与奉神刀，出逃国外。该犯先是流窜至我国边境之挪德卡莱边疆区，以其自称的稻妻武士身份招摇撞骗，遭秘闻馆揭穿之后，又窜入女皇陛下之神圣首都至冬堡，意图再次行骗。然而在意外发现恃其骇人装束便可肆行劫掠后，该犯便屡施故技，终于在引发全城恐慌后被我方抓获。
由于该犯系外逃人员，稻妻官方拒绝承认其侨民身份，因此等待他的将是至冬法律的审判。此案后续进展如何，还请继续关注本报消息。

<title name = 达尔杜佛的至冬游记！/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_09/>
<center>《达尔杜佛的至冬游记！》</center>
（编者按：本文为枫丹作家达尔杜佛于一百三十八年前写下的至冬游记，后经证实，达尔杜佛一生都没有离开过枫丹。）
（又按：为避免读者因原文的事实谬误产生误解，编者已特意标注出文章中不符合至冬现实、或者容易引发误会的表述。）
…我们的大陆上有这样一个冰雪眷顾的国度，它曾令诸多冒险家神往，但对寒冷的恐惧使他们绕行在边境线外。于是，这个国度变成一个模糊的、巨大的象征，以至于史学家开始怀疑它根本不存在。我也曾眺望过它，或者绕行，直到最终克服了对神秘的恐惧。我终于看到了它——透过列车的玻璃窗，至冬在那里。
至冬，这个国度的居民中，没有一个畏惧严寒，只因在无尽风雪覆盖的土地下，生长着可以燃烧的宝石[1]。人类只是其中一种具有智慧的生命，哪怕是一只猎犬、一只高昂着头颅的猫咪，甚至是你路过的一棵大树，都有可能在不经意之间口吐古老又文雅的语言[2]。
在这片土地上，人们没有饮用咖啡的习惯，因为大地上的任何作物都能被酿造成好酒。一位贵族邀请我品尝了他们的一种名为「格瓦斯」的国民饮料，口感与枫达有些微妙的相像。他告诉我，一些至冬堡的王公曾经考虑过前往枫丹廷旅游居住[3]，但考虑到格瓦斯并不在枫丹售卖，便打消了这个念头。

<title name = 《冰上舞曲》今日来稿：这究竟是什么样的演出？/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_01/>
<center>《冰上舞曲》今日来稿：《这究竟是什么样的演出？》</center>
最近在至冬堡上演的《海鸟》，是笔者几十年来所见最糟糕之剧目！依演出呈现而言，它既非能唤醒观众崇高悲痛的严肃作品，亦非能令人放声大笑的滑稽喜剧。
观众在《海鸟》里，究竟还能找到些什么？这部以「先锋」与「现实」为噱头的作品，竟只显示出作者对舞台技巧的毫不娴熟了！英雄乃一部戏应该有之主要人物。而在《海鸟》里，英雄并不存在。所谓主角，不过是一个怯懦男人，加上一个失败女人。他们缺乏行动，对命运无比顺从，尽是小角色神气，未有一个能引发演员演出之兴致。
另，一部优秀作品所应有之曲折，被《海鸟》全然抛弃。平淡的推进里，夹杂着漫长停顿，这便是该剧目的结构特征了。无人为伟大事业牺牲，更无人得到拯救，因此，这剧目自是没有什么可谈的了，布局和主题，亦是两句话便能说完。
舞剧一向是至冬之瑰宝，可《海鸟》却以「先锋」为借口，抛弃了这瑰宝的一切优秀传统。它不曾留下动人心魄之故事，只显现出散了架的结构、烦恼的小人物，还有无关紧要的蝇虫。呜呼，此等作品竟能现世，笔者为此感到万分痛心！
（撰稿人：特里果林）
