<title name = 《怪语奇谭》本期投稿：奥古洛夫诡谈/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_10/>
<center>《怪语奇谭》本期投稿：《奥古洛夫诡谈》</center>
大家都知道，毛虫在树叶里做茧，就会变成不祥的飞蛾；烂泥里有青蛙的种子，后来长出了腿，才变成了可以跳可以游的青蛙。古老的妖精传说中，还认为人死后埋在地下，血肉腐烂了，脊椎骨就会变成一条蛇。

生命的起始，总与生命的完成形态有所不同。但唯有一只鸟，它从出生起，就是一个样子了。

风景清丽的山谷深处，住着一只美丽的让人移不开眼睛的火鸟。它张开翅膀可以遮蔽天空，眼睛像宝石，羽毛像金子，只要见到它的人，就会跟随它步入山谷的深处，成为它钟爱的食粮。

当然，火鸟并不喜爱啄食腥臭的血肉，它喜食人的记忆。

记忆是宽敞的宫殿，是灵魂的居所。没有记忆，人就不能称之为人。被火鸟吞食「记忆」后，人便会失去感官、情感与语言，退化成无知觉的树木，团团围绕这座山谷中的小镇，遮挡外来者的视线。而火鸟只需静静地等待，等待下一个好奇的来客靠近。

当然，时间会在火鸟身上留下衰老的痕迹，利器也会在它身上留下伤痕，死亡并不会远离这只美丽的火鸟，但是新的生机会眷顾它。当清风吹拂，已然无用的躯壳开始在阳光下泛起温热，来自「生」的火焰点燃火鸟绚丽的羽叶，它在滚烫的烈火中拍打双翼，落于空中的灰烬中滋养出新的血肉。最终，火鸟会再次披上华丽的盛装，盘旋于奥古洛夫镇上空，静静凝视着每一个被它的美丽所吸引的过客。

（所以，笔者倾情建议各位读者，珍爱生命，远离奥古洛夫镇，毕竟大家不能像火鸟一样，一遍一遍地重生嘛！）

<title name = 警惕保险骗局，守护摩拉安全/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_04/>
<center>《警惕保险骗局，守护摩拉安全》</center>
「投保时信誓旦旦，理赔时一分没有」？近日，关于至冬保险陷阱的传闻甚嚣尘上，经过深入调查后，本报记者发现，相关案件都与名为「幸福至冬保险公司」的机构有关。

去年，一位蒙德旅客在该公司投保，为自己的臻冰鱼竿购买了「臻冰造物融化险」。该保险内容为：若是受保制品融化，受益人将获得最高20万摩拉。该旅客随后返回蒙德垂钓，鱼竿融化。旅客向保险公司索赔，保险公司却声称：该保险明确有「需证明受保制品在至冬境内融化」的条款，因此不能予以赔偿。

无独有偶，一位至冬堡市民也于近期在该公司的保险产品上遇到理赔问题。这位不愿透露姓名的市民表示，自己本是一个艺术演出爱好者，但近年至冬堡戏剧演出质量良莠不齐，为此她购买了该公司推出的「观剧创伤修复险」。然而，当她真的因为观赏了一部糟糕剧作，导致三天喝不下最爱的冰醋栗原浆，遂前去找该公司理赔时，保险公司表示：该保险的理赔条件是受保人需证明自己真的因为观剧受到了精神创伤，而该受保人既然能自行前来理赔，就说明她精神正常。

目前，至冬堡方面已经对该公司进行立案调查。同时，运输局提醒广大至冬群众：务必擦亮双眼，谨防保险陷阱，守护摩拉安全；另，若要购买列车延误险，请选择运输局官方推出的保险产品，保障好自己的权益。

<center>《雪国热议》本期投稿：《历史重影说》</center>
提瓦特新编年史·至冬篇（其五）
历史重影——虚构还是科学？

在先前的连载中，笔者曾提出如下判断：主流史学界笃信的伪史，与至冬的信史，两者之间存在显著的相似。其程度之高，已经不足以再用单纯的文化接触或传说流转来解释。

笔者开创性地将这一现象总结为「历史重影」：表面上来自不同区域、不同时代的文字记录，实际上是同一历史在不同视角下的反复改写——这段被掩盖的历史就是莫诺马赫皇帝的征服史。

在莫诺马赫皇帝统治时期，全提瓦特的大部分区域，实际上都处于同一个沙皇国的统治下。

笔者曾翻阅过冒险家协会的报告，如今的诸国皆存在建筑风格相对统一的——与我们在至冬见到的遗迹风格相近的——古代遗迹。这是不可辩驳的事实。而这个统一的文明，很明显就是莫诺马赫皇帝的国度。
