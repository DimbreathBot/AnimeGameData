<title name = 最新天文大發現！月球上的神秘生物？/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_01/>
<center>《最新天文大發現！月球上的神秘生物？》</center>
本報昨日接獲來自極北之地（由於相關研究成果尚未發表，出於保密原則，詳細位置本報不便透露）天文臺的最新消息，著名天文學家伊凡·赫歇列夫博士憑藉他的新型巨顯微望遠鏡，已成功觀測到月球表面之絕景。
新型巨顯微望遠鏡的設計原理來自於赫歇列夫博士的天才構想，他透過將一臺高達二十四倍放大的高倍複式顯微鏡安置在長度達七十餘呎的巨型望遠鏡的目鏡之上，從而創造性地突破了傳統光學的極限，並輔以高度精煉的克什尼克晶礦燃起的強光照射，實現了前所未有的超高倍率放大效果。
據悉，軍械宮為這項不可思議的專案撥付了資金，但在此前卻從未向公眾披露，也未將其列入每年的預算報表當中。對此，赫歇列夫博士表示，為在各國之間的科學競賽中獨占鰲頭，愚人眾方面早已關照參與各方均須嚴格保密，或許這就是為什麼我們直到今天才知曉這項刺破宇宙帷幕的先驅專案存在。
在赫歇列夫博士委託本報發表的信件中，詳細描繪了他所觀測到的月球表面風景，包括森林、河流、山谷與草原，以及生活在月球上的諸多神奇生物：野牛、鯨魚、水母…甚至還有企鵝！
此外，赫歇列夫博士還特別提到他在月球上發現了疑似智慧生物留下的痕跡——一座由藍色晶石建造而成的宮殿，其塔樓正指向了我們！建造它的人們想要向我們傳達什麼樣的訊息？是想宣告他們文明的輝煌，又或是警告我們未來將要面臨的災禍？
在信件的最後，赫歇列夫博士還提到了一種無法確定其真實身分的類人生物。牠長著金色的毛髮，背上有一對薄膜翅膀，徘徊在望遠鏡視野的各處。可惜的是，在拍攝到其樣貌前，觀測就被迫中止了。原因是赫歇列夫博士在睡前忘記將望遠鏡降下放平，導致太陽升起後，穿過鏡頭的陽光經透鏡聚焦引發了火災。所幸在場的工作人員及時處理，未造成人員傷亡。
雖然本次觀測由於意外事故被迫中止，但取得的成就已足以震撼科學界。雖有因循守舊的學院派研究員質疑此研究成果「純屬虛構」，但來自教令院明論派的學者們已對這項研究做出了高度的評價，有多名訶般荼在讀到信中所披露的研究成果時，激動得當場昏厥。
之後本報將分六期刊載赫歇列夫博士委託本報發表的信件全文，請渴望瞭解月球真相的讀者朋友們切勿錯過！

<title name = 《怪語奇譚》本期投稿：消失的獸怪礦工/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_09/>
<center>《怪語奇譚》本期投稿：《消失的獸怪礦工》</center>
馬蒙托夫來稿

這是從朋友的朋友那裡聽來的故事。

利斯岑是在運輸局工作不到一年的新人，他出身彩冰鎮，過去最大的夢想就是離開家鄉，到至冬堡或是新基捷城這樣的大城市生活。現在他的夢想實現了一半，他作為列車員所負責的正是連通新基捷城、至冬堡和彩冰鎮三地的線路。
他憑藉著外向健談的個性，很快和常乘坐這個路線往來的旅客熟絡起來，也從和他們的閒聊中獲得了不少可堪解乏的話題。「契科塔」警探透露的案件內情、雪精講述的赫斯珀利德斯之館傳說，諸如此類的消息總能讓他在回老家和從未走出家鄉的老友敘舊時，態度也高了幾分。因此他很喜歡這份工作，動機姑且不論，他的確一度對工作投入了熱情，直到讓他大病一場的那次事件。

那天對利斯岑來說是再普通不過的一天，車廂裡有幾個返校學生、討論新劇目的年輕夫婦、高大而憂鬱的雪精、一些獸怪礦工…其中不乏他熟悉的面孔。
獸怪礦工頗有些興奮，據他們說，在新基捷城以西很遠的地方挖到了什麼不便聲張的東西。儘管不便聲張，他們還是忍不住向其他人分享了，看來是真的很不得了的東西。「如果是從基捷城的舊址裡拿了什麼，最好盡快歸還，否則會遭遇不幸。」聽到了他們的對話，憂鬱的雪精如此警告。
利斯岑打了個寒顫，好像這番話有立竿見影的效果，他檢查了列車上的供暖裝置，運轉正常，但那股異樣的寒氣卻似乎始終縈繞在車廂之中。他有些猶豫這件事是否應該彙報給上級，好讓警探來介入調查。他想當個盡職的列車員，但他不想當一個可恥的告密者。

不過這兩難的境地並未讓他困擾太久，因為當天晚上他就發起了高燒，這對一向身體健康的他來說是非常罕見的。原因不明的高燒讓他不得不告病一個禮拜，甚至在重返崗位後仍自覺十分虛弱，身體狀況大不如前。
據運輸局的同僚說，那班列車上的其他乘客也幾乎在同一時間病倒了，有些身體孱弱的至今尚未恢復。這位同僚在新基捷城還有位親戚，有通靈的本事，他特意就這次的事件諮詢了那位親戚的意見，得到的答覆是：那幾個獸怪礦工受了黑神的詛咒，把不乾淨的東西帶到了列車上，乘客還有利斯岑都是因為邪靈入侵才生了怪病。利斯岑本打算反駁，但想到那天好像蛇一樣從腳底爬上來的寒氣，到嘴邊的話又吞了下去。

再後來，利斯岑再也沒見過那幾個獸怪礦工，也沒有聽過他們的消息。或許是工作原因他們才不再乘坐這趟列車，又或許是被觸怒的黑神將他們…無論如何，他們的身影，或是存在本身，就像是被凍原上無休止的風雪給抹除了一般，再也尋不到一絲痕跡…

<title name = 關於禁止部分旅客乘車的聲明/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_04/>
<center>《關於禁止部分旅客乘車的聲明》</center>
據本報報導，近日，運輸局公布了最新的禁止乘車旅客名單，引發民眾熱議。其中，雪精伊·尼·伊瓦諾夫先生因「無任何違規行為卻遭禁乘」向運輸局提起強烈抗議，認為此舉侵犯了自身的合法權益。
昨日，運輸局對此作出了正式答覆，並揭示了禁令背後的無奈真相。據運輸局調查，雪精伊瓦諾夫先生頻繁購票乘坐往返至冬堡與新基捷城的列車，實為悼念自己過世的戀人——她曾作為列車員在此條線路任職——然而，伊瓦諾夫先生每每在車廂內睹物思人，陷入哀慟時，就會無意識地強化自己作為雪精的能力，導致車廂溫度驟降，因此而罹患嚴重風寒的旅客不計其數。
運輸局強調，伊瓦諾夫先生本人雖無惡意，但為保障廣大旅客的身體健康與外出安全，運輸局不得不做出禁止其乘車的決定，希望市民朋友能對此予以體諒和諒解。
