<title name = 窃盗は否定！殺人は認める？——「雪原の星」窃盗事件に関する続報/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_04/>
<center>『窃盗は否定！殺人は認める？——「雪原の星」窃盗事件に関する続報』</center>
本誌の独自入手による報道。

スネージナヤ皇立軌道運輸局の発表によると、近日「雪原の星」事件に重大な進展があり、事件の容疑者がすでに逮捕されたとのこと。

取調べを担当した警察隊員ユディンチェフ氏によると、事件発生当日の未明、V・ブヤノフ容疑者（仮名）が被害者宅に侵入し、非常に希少価値のある宝石「雪原の星」を盗み出し、被害者のA・ワラニコフさん（仮名）を殺害したという。

取調べの最中、ブヤノフ容疑者（仮名）は「雪原の星」の盗難に関してははっきりと否定したが、殺人の嫌疑については自白した。

「間違いありません。あの高利貸しの詐欺師、ワラニコフ（仮名）を殺したのは私です…でも私は何も盗んじゃいない。自首したのは、私が殺したのが単なる人にはとどまらないからです。実のところ、人を殺す腕前も大したことはありませんが——私は原則、原則を殺したんです！わかりますか？殺人の罪を自白しにきたのに、あなたは私がくだらない財宝を奪ったと主張している。あなたは善良な人ですが、その容疑だけは受け入れられません。」

しかし、被害者であるワラニコフさん（仮名）のパートナーの女性は、この主張に対し激しい言葉で反論した。

「…哀れなワラニコフ（仮名）のことは置いておくとして、雪原の星を盗んだのがあの殺人犯でないなら、一体誰が犯人だというの？女皇陛下の御名のもと、今すぐ彼を絞首台に送ることを要求するわ！雪原の星については、すぐに『紛失』として記録してちょうだい。それ以上追う必要はないわ…ワラニコフ（仮名）の葬儀のほうが、雪原の星の行方よりもずっと重要でしょう？殺人犯はもう捕まっているのだから、もはや宝石の一つや二つがどうなろうと重要なことじゃないわ…」

この事件の続報について、本誌は引き続き追跡していく予定である。

<title name = 皇都の治安改善の朗報続々！数週間にわたり市民を脅かした「浮浪武士」、本日ついに逮捕！/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_02/>
<center>『皇都の治安改善の朗報続々！数週間にわたり市民を脅かした「浮浪武士」、本日ついに逮捕！』</center>
本誌特報。最近、スネージナヤ・グラード市民を数週間にわたり不安に陥れていた稲妻の「浮浪武士」事件が昨日未明の犯人逮捕をもって幕を閉じ、街全体を覆っていた恐怖の影は完全に払拭された。
数週間にわたり、スネージナヤ・グラードのダウンタウンの複数街区、さらにはグルポフ外の人気のない小道において、深夜に悪質な事件が頻発していた。目撃者によれば、犯人はぼろぼろの緋色の具足を身に着け、奇妙な仮面を被った「海乱鬼」であったという。その恐ろしい風貌と異様な刀さばきにより、多くの被害者は相手が言葉を発する前に驚いて財物を投げ捨て、逃走したという。被害者の数が増えるにつれ、街中の市民が恐怖と不安に包まれていった。
幸い、優秀なスネージナヤ・グラード警察局長の直接指揮のもと、警察局所属の捜査課と冬契軍パトロール隊の緊密な協力により、昼夜を問わず徹底した捜査が行われた。そしてついに昨晩遅く、ダウンタウンにあるパン屋の廃墟の中で犯人のものと思しき痕跡を発見した。その後、武装して犯行に出ようと外に出た瞬間を狙い、周囲に張り込んでいた優秀な捜査員たちが一斉に踏み込み、その場で取り押さえることに成功した！
調査によると、この犯人はもともと稲妻の離島で営業許可を持つ商人であったが、当地を管理する勘定奉行との間で調停不可能な利益紛争が生じ、一昨年にその商会は完全破産したという。平民に成り下がることが納得できなかった犯人は進退窮まった末、当地の神社に奉納されていた緋色の具足と奉神刀を盗み出し、国外へと逃亡。まず我が国の国境沿いにあるノルドカール辺境区に至り、稲妻の武士を自称して詐欺を働いたが、秘聞の館に正体を暴かれると今度は女皇陛下の神聖なる首都、スネージナヤ・グラードへと潜入し、再び詐欺を働いた。その恐ろしい出で立ちさえあれば堂々と略奪が行えることに意図せず気づいた後は同じ手口を繰り返すようになり、ついには街全体を恐怖に陥れたのち、逮捕されるに至った。
犯人は国外逃亡者であるため、稲妻当局は在外国民としての身分を認めておらず、犯人はスネージナヤの法律のもとで裁判にかけられることとなる。本件の続報については、引き続き本誌からの発表をお待ちいただきたい。

<title name = 『世にも奇妙な話』本号の内容：霜の精の魔法使い/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_09/>
<center>『世にも奇妙な話』本号の内容：『霜の精の魔法使い』</center>
投稿者：シャゴワ（仮名）

あたしはシャゴワ、冒険者よ。数日前、雇い主からの依頼でスネージナヤの最も辺境にあって一番危険な雪原に一人で向かったの。（そんな危険な雪原にどうして一人で向かったのかは聞かないでね。そりゃあ報酬を独り占めするためだし、あたしって結構腕がいいんだから！）

で、準備は万全だったにもかかわらず、不運にも急な猛吹雪に襲われて方向を完全に見失っちゃったの。とんでもない寒さで、このまま凍死するのかと思ったわ。そのとき、あたしのお婆ちゃんが昔教えてくれた話をふと思い出して——

「いいかい…広大な雪原の中でその古いおまじないを唱えれば、霜の精の魔法使いが吹雪の奥から姿を現すはずだよ。ただし覚えておくんだ。彼女の名を呼んでいいのは、最も暗く、最も絶望的な危機に陥ったときだけなんだよ…」

しばらく考えて、あたしはついに幼い頃の記憶の中からそのおまじないを思い出したの。「ハスクラトゥラブカジスマヴィッツクポルムゴジナドゥック。」（なんて説明すればいいのかな。これ、デタラメなんかじゃないからね！こんなどうでもいい情報を覚えててくれた、あたしの脳みそに感謝だわ！）

とにかく、霜の精の魔法使いは本当に現れたの。箒に乗ってて、後ろにはまんまるの霜の精の群れを引き連れていた。彼女はあたしを雪原から救い出して、自分の庭に連れていってくれたわ。もちろん、新たな困難も待ち受けていた——霜の精の魔法使いが言うには、彼女の願いを叶えることができたらあたしを家に帰してくれるけど、叶えられなかったら花の肥料にしてやる、だって。

彼女の願いが何だったのかって？彼女は、霜の精のコーラスグループを作ろうとしていたの。でも霜の精たちは言うことを聞かなくて、いつも歌はめちゃくちゃ——それで彼女は、翌朝の夜明けまでに、きちんと訓練されて団結した霜の精のコーラスグループを見せるよう、あたしに要求してきたの。

どうやって成し遂げたかは置いといてね。とにかく、花の肥料にされなかったのは本当に幸運だったよ。
（まぁ残念なことに、雪原の奥深くまで入り込んだっていうのに雇い主の依頼は達成できなかったんだけどね。ああ、あたしの報酬が…）

これを読んでくれたみんなに、霜の精を召喚するおまじないを教えてあげるわ。いつか、あなたの命を助けてくれるかも？

「ハスクラトゥラブカジスマヴィッツクポルムゴジナドゥック！」

…まぁ、このおまじないを唱えても花の肥料にされちゃうかもしれないけど、もしかしたら、しっかり訓練されて団結した霜の精たちの素敵な合唱が聴けるかもね！
