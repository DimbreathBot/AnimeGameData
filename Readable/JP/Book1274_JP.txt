<title name = 最新天文大発見！月面の謎の生物？/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_01/>
<center>『最新天文大発見！月面の謎の生物？』</center>
本紙は昨日、極北の地（関連研究成果が未発表であるため、機密保持の観点から具体的な場所については明らかにできない）にある天文台より最新情報を入手した。それによると、著名な天文学者イヴァン・ヘルシェレフ博士が、新型の巨大顕微望遠鏡を用いて月面の絶景を観測することに成功したという。
この新型巨大顕微望遠鏡の設計原理は、ヘルシェレフ博士の天才的な発想から編み出された。博士は最大二十四倍の高倍率を誇る複式顕微鏡を、全長七十フィート余りにも及ぶ巨大望遠鏡の接眼部に取り付けるという独創的な方法で、従来の光学技術の限界を打ち破った。さらに高度に精錬されたクルースニク晶鉱が燃焼時に発生させる強烈な光を照射することで、これまでにない超高倍率の拡大観測を実現した。
情報によると、オルジェイナヤ・パラタはこの不可思議なプロジェクトに資金を拠出していたが、これまでは一般に公表されることはなく、毎年の予算報告にも記載されていなかったという。これについてヘシェレフ博士は、各国間の科学競争において首位に立つため、ファデュイ側が以前から関係者に対して厳格に守秘義務を課していたと述べており、宇宙の帳を突き破るこの最先端プロジェクトの存在を私たちが今日まで知らなかったのは、おそらくそれが理由だろう。
ヘシェレフ博士が本紙に発表を依頼した書簡には、彼が観測した月面の風景（森、川、谷、草原を含む）や、月面に生息する数多くの不思議な生物——牛、鯨、クラゲ…さらにはペンギンまでもが詳細に描かれている！
さらに、ヘシェレフ博士は、月面で知恵ある生物が残したと思われる痕跡を発見したことについても特筆している。それは青い晶石で建造された宮殿であり、その塔楼はまっすぐ私たちの方を指しているという。それを建造した人は、私たちにどのようなメッセージを伝えようとしているのだろうか？彼らの文明が煌めくものであると宣言したいのか、それとも私たちが将来直面する災厄を警告しているのだろうか？
ヘルシェレフ博士は手紙の最後で、人間に類似した正体不明の生物についても言及している。金色の毛に覆われ、背中に一対の薄い膜状の翼を備えたその生物は、望遠鏡の視野内のあちこちを徘徊していたという。残念ながら、その姿を撮影する前に観測は中止を余儀なくされた。というのも、博士がうっかり望遠鏡を水平に戻さず就寝してしまったため、日の出後、レンズを通過した太陽光の収れん現象が起こり、火災が発生してしまったのだ。幸い、現場の職員が迅速に対処し、死傷者は出なかった。
今回の観測は不慮の事故により中止を余儀なくされたが、獲得した成果は科学界を震撼させるのに十分なものであった。保守的な学院派の研究員の中には、この研究成果を「全くの作り話」であると疑う者もいるが、教令院明論派の学者たちはすでにこの研究に対して高い評価を下しており、書簡で明かされた研究成果を読んだ複数のハーバッドが、興奮のあまりその場で気絶したほどである。
今後、本紙ではヘシェレフ博士が本紙に発表を委託した書簡の全文を、全六回に分けて掲載する予定です。月の真相を知りたいと願う読者の皆様、絶対にお見逃しなく！

<title name = 『怪語奇譚』今号投稿：消えた異怪の獣の鉱夫/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_09/>
<center>『怪語奇譚』今号投稿：『消えた異怪の獣の鉱夫』</center>
マモントフ寄稿

これは友達の友達から聞いた話だ。

リスツェンは運輸局に勤めてまだ一年に満たない新人で、スヴェトロレドフカの出身だった。かつての最大の夢は故郷を離れ、スネージナヤ・グラードやノヴォキッチェヴのような大都市で暮らすことだった。そして、その夢はすでに半分叶っていた。というのも、乗務員として担当していたのが、ちょうどノヴォキッチェヴ、スネージナヤ・グラード、スヴェトロレドフカの三都市を結ぶ路線だったのだ。
外向的で話し上手な彼は、あっという間に列車の常連客たちと打ち解け、他愛ない雑談の中から気晴らしにちょうどいい話の種をたっぷりと仕入れていた。「チェコタ」の刑事が漏らした事件の内情、雪の精が語るヘスペリデスの館の伝説――そういった話題のおかげで、一度も地元を出たことのない旧友たちとの帰省時の会話では、少しばかり鼻が高くなれる。だからこそ彼はこの仕事をとても気に入っていたし、理由はともかく、あの出来事でひどく体を壊すまでの間は、確かに熱意を持って働いていた。

その日はリスツェンにとってごく普通の一日だった。車両には休暇明けで学校に戻る学生たち、上演された新作の演劇について語り合う若い夫婦、大柄で物憂げな雪の精、そして異怪の獣の鉱夫たち…中には見知った顔もいた。
異怪の獣の鉱夫たちはかなり興奮した様子だった。彼らの話によれば、ノヴォキッチェヴの西方はるか遠くで、大きな声では言えない「何か」を掘り当てたという。秘密にしていたほうがいいとは分かっていながらも、彼らは辛抱できずに他の乗客に漏らしてしまったようだ。よほどの代物なのだろう。「キッチェヴの旧跡から何かを持ち出したのであれば、一刻も早く戻したほうがいい。さもなくば不幸が降りかかるぞ。」会話を耳にした物憂げな雪の精はそう警告した。
雪の精の言葉に影響されたか、リスチェンは身震いをした。列車の暖房装置を確認してみたが、特に異常はない。それなのに、車内が妙に冷たい空気に包まれているような気がした。今聞いた話を上司に報告し、刑事に介入してもらうべきかどうかと彼は迷った。職務に忠実な乗務員でありたかったが、恥ずべき密告者にはなりたくない。

しかし、そんな板挟みの悩みは長くは続かなかった。その夜、彼は高熱を出してそれどころではなくなったのだ。普段から健康そのものの彼は、熱を出すことなどめったになかった。原因不明の高熱で一週間の病欠を余儀なくされ、復帰後も体力は衰え、全身の状態が以前と比べ物にならないほど悪くなっていた。
運輸局の同僚の話では、あの列車に乗り合わせた他の乗客たちもほぼ同じ頃に倒れ、中には元々病弱で今も回復していない人がいるという。さらに、その同僚にはノヴォキッチェヴに親戚がいて、霊感の持ち主だそうで、今回の出来事について意見を求めたところ、こんな答えが返ってきた――例の異怪の獣の鉱夫たちはチェルノボーグの呪いをかけられ、穢れた物を列車に持ち込んだ。乗客たちも、そしてリスツェンも、悪霊に侵されて奇妙な病にかかったのだ、と。リスツェンは反論しようとしたが、あの日、まるで蛇のように足元から這い上がってきた寒気を思い出すと、喉まで出かかった言葉をそのまま飲み込んでしまった。

以来、リスツェンがあの異怪の獣の鉱夫たちと顔を合わせることは二度となく、消息を耳にすることもなかった。仕事の都合で彼の担当する列車には乗らなくなったのかもしれないし、あるいはチェルノボーグの怒りを買ったことで彼らは…いずれにせよ、凍土に絶えず吹き荒れる吹雪に消し去られたかのように、彼らの姿、いや、存在そのものが、跡形もなく見失われたのだった…

<title name = 一部乗客の乗車禁止に関する声明/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_04/>
<center>『一部乗客の乗車禁止に関する声明』</center>
本紙の取材によると、運輸局はこのほど最新の乗車禁止者リストを公表し、市民の間で大きな話題となっている。中でも雪の精イ・二・イワノフ氏は「いかなる違反行為もなしに乗車を禁じられた」として運輸局に強く抗議し、本措置が自身の正当な権利を侵害するものだと訴えている。
昨日、運輸局はこの件に対して正式に回答し、禁止措置に至った心苦しい経緯を明らかにした。運輸局の調査によると、雪の精イワノフ氏はスネージナヤ・グラードとノヴォキッチェヴを往復する列車を頻繁に利用していたが、それはかつてこの路線の乗務員で、故人となった恋人を偲ぶためであった。しかし、イワノフ氏は車内で恋人を思い出すたびに深い悲しみに包まれ、そのせいで雪の精の能力が無意識に強化されてしまっていた。結果、車内温度が急激に低下し、これまでに数多くの乗客がひどい風邪にかかっていたのである。
運輸局は、イワノフ氏本人に悪意はないものの、大勢の乗客の健康と安全な運行のため、同氏の乗車を禁止するという決定を下さざるをえなかったと強調しており、市民へ理解を求めている。
