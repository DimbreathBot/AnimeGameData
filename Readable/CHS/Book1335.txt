<title name = 假扮运输局警探查询「鉴定细节」？酿酒厂员工切勿受骗！/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_08/>
<center>《假扮运输局警探查询「鉴定细节」？酿酒厂员工切勿受骗！》</center>
本报讯，近日，至冬皇家轨道运输局缴获了一批私酒作坊仿制的「假火水」，顺「假水火」的销售线路，成功打击了三处制造、运输、贩卖劣质酒水的不合规工坊，收缴摩拉一千余万。

「假火水」一直是至冬官方重点打击对象，只是这次的「假火水」仿制十分到位，尽管酒液本身质量堪忧，可是不管是装酒的瓶身细节，酒瓶瓶盖或是瓶身标签的防伪印刷处都与真品别无二致。

经过调查，原来是私酒作坊的犯罪团伙在进行仿制之前，伪造证件假扮运输局警探，以搜查鉴定伪劣产品为由，询问商家「鉴定细节」，商家为了配合官方调查，不仅提供了防伪设计，还提供了瓶身样品，私酒作坊以此仿制了「假火水」的酒瓶与包装。

再次提醒，运输局的警探并不会因各种原因要求商家提供防伪设计细节、讨要样品、为调查预付摩拉或是进行如何规避至冬法律条款的付费咨询，谨记保护好一切敏感信息。

<title name = 从窗户跳进雪堆刺激又有趣？可能导致严重后果…/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_02/>
<center>《从窗户跳进雪堆刺激又有趣？可能导致严重后果…》</center>
随着气温进一步的下降，连续几日的降雪量也达到了历史记载的高点，为了清理出通行的道路，街道清理人员会将街道清理出的雪暂时堆在居民区建筑外墙下。

有孩童和心智与孩童仿佛的至冬居民抓住这样的机会，开始了一项危险的游戏——即从高处的窗户直接跃入窗户下的雪堆中。此举或许能够带来一时的快乐，却也容易产生一系列的纠纷，甚至已令多人不慎受伤。

根据本报记者调查，在短短数日内就已发生三起因「跳下雪堆」产生的纠纷了。

居住在炉灰区的女童A某，在跳下雪堆时才发现雪堆下居然有人放置了臻冰发射台，以至于被弹射向了街道另一侧的屋顶，被困数个小时后才被接到报告的运输局员工解救下来。

居住在炉灰区的少年B某，在跳下雪堆后发现雪堆下的是前一日因为醉酒而跌入雪堆的妖精C某，导致C某的手臂受到了严重伤害。

居住在极星区的男士D某，在跳下雪堆后，惊醒了雪堆中前一日因为醉酒而跌入雪堆的妖精E某，幸运的是，跳跃的落点在E某周围，未使后者遭受如前一个事件中C某所受的重伤。不幸的是，因此被激怒惊醒的妖精E某下意识重击了D某，令D某手臂受到了严重伤害。

本报提醒，追求刺激与有趣是个人选择，但也不能忽视过程中的安全隐患与可能对他人造成的困扰。

<title name = 臻冰展品失窃后被追回，展会负责人盛赞「行动力超群」！/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_09/>
<center>《臻冰展品失窃后被追回，展会负责人盛赞「行动力超群」！》</center>
本报讯，于采冰镇举办的臻冰雕像展览「经典再冻结：冰星果派大师作品（复刻）特展」正在如火如荼的举办之中。

但在此期间，发生了冰星果派大师作品的复刻品被人窃取，甚至企图盗往至冬国外的事件。好在至冬皇家轨道运输局的警探及时发现，在窃取者即将出镜前将之逮捕并缉拿归案，被窃取的臻冰展品也成功物归原主。

展览的举办方也对此表示了感谢：

「呃…很感谢运输局的警探们，虽然…呃，毕竟是复刻特展，被窃取的也都是不太值钱的复刻品，而且处理起来蛮麻烦所以本身就打算在展览后抽选赠送…所以就算被窃取也不会感到困扰…」

「但…总之还是感谢运输局，这个办事效率确实是挺高的。」

法网恢恢，疏而不漏，至冬皇家轨道运输局的警探们的高效行动向大家证明了：即使是出境后过不了多久就会融化的臻冰造物，运输局也会在融化之前将之追回！
