<title name = 運輸局の刑事を騙り「鑑定の詳細」を確認？醸造所スタッフは騙されないように！/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_08/>
<center>『運輸局の刑事を騙り「鑑定の詳細」を確認？醸造所スタッフは騙されないように！』</center>
【本紙報道】先日、スネージナヤ皇立軌道運輸局は、密造酒工房によって模造された「偽炎水」を押収した。さらに、この「偽炎水」の販売ルートをたどり、粗悪なドリンクの製造、輸送、販売を行っていた三箇所の違法工房の摘発に成功し、1000万モラ余りを没収した。

「偽炎水」は常にスネージナヤ当局の重点的な取り締まり対象となってきた。ただ、今回の「偽炎水」は非常に精巧に模造されており、その品質こそ粗末なものの、酒瓶の細部やボトルキャップ、そして瓶のラベルにある偽造防止印刷に至るまで、本物と全く見分けがつかない。

調査の結果、密造酒工房の犯罪集団が模造を行う前に、身分証を偽造して運輸局の刑事に成りすまし、偽造品や粗悪品の捜査・鑑定を理由に、業者へ「鑑定の詳細」を確認していたことが判明した。業者は公式の調査に協力しようと偽造防止デザインだけでなくボトルのサンプルまでも提供してしまい、密造酒工房はこれを元に「偽炎水」のボトルとパッケージを模造していたのだ。

運輸局の刑事がいかなる理由であれ、業者に対して偽造防止デザインの詳細の提供を求めたり、サンプルを要求したり、調査を名目にモラの前払いをさせたり、スネージナヤの法律条項を回避する方法について有料で相談を行ったりすることは決してない。あらゆる機密情報の保護を徹底するよう、くれぐれもご注意願いたい。

<title name = 窓から雪の山に飛び込むのはスリルがあって面白い？深刻な結果を招く可能性も…/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_02/>
<center>『窓から雪の山に飛び込むのはスリルがあって面白い？深刻な結果を招く可能性も…』</center>
気温がさらに低下するにつれ、ここ数日間の降雪量も過去最高記録に達している。通行ルートを確保すべく、街の清掃作業員は通りから除雪した雪を一時的に居住区の建物の外壁の下に積み上げている。

子供や童心を忘れぬスネージナヤの住民の中には、これを機に危険な遊びを始める者が現れた。高い窓から、下に積もった雪山へ飛び込むというものだ。一時の楽しみにはなるかもしれないが、すでに問題が生じており、不注意から怪我をする者も相次いでいる。

本紙記者の調査によると、わずか数日の間に「雪の山に飛び降り」ることによるトラブルが三件も発生している。

ゾルヌィ区の少女Aは、雪山に飛び降りたところ、なんとその下に真氷発射台が設置されていたため、通りの向かい側の屋根まで飛ばされてしまった。数時間にわたって取り残された末、通報を受けた運輸局の職員によってようやく救助された。

さらに、ゾルヌィ区の少年Bは雪山から飛び降りた際、その下にいたのが前日に酔って雪山へ転落したフェイCだと判明。結果、Cの腕に重傷を負わせた。

アルクティカ区の男性Dは雪山から飛び降りた際、前日に酔って転落し、その中で眠っていたフェイEを驚かせて起こしてしまった。幸い、D氏の着地点はE氏のすぐそばだったため、C氏が負ったような重傷は免れた。しかし、怒って目を覚ましたE氏が無意識にD氏へ強烈な一撃を放ち、結局D氏は腕に重傷を負ってしまった。

スリルや楽しさを求めるのは自由だが、潜在的なリスクや他人に迷惑をかける可能性があることを軽視してはならないことを、周知しておきたい。

<title name = 盗難に遭った真氷の展示品、無事回収。責任者は「抜群の行動力」と大絶賛！/>
<image preview name = UI_Img_SnezhnayaNewspaperPage_Pic_09/>
<center>『盗難に遭った真氷の展示品、無事回収。責任者は「抜群の行動力」と大絶賛！』</center>
本紙報道。スヴェトロレドフカで開催中の真氷彫像展「名作再凍結——グレイシア派巨匠復元作特別展」が現在、大盛況を博している。

しかしこの期間中、グレイシア派の巨匠による作品の復元作が盗まれ、スネージナヤ国外へ持ち出されそうになる事件が発生した。幸い、スネージナヤ皇立軌道運輸局の刑事がいち早く察知し、犯人の出国直前に逮捕・連行。盗まれた真氷の展示品も、無事に持ち主のもとへ返還された。

展覧会の主催者も、これに対して感謝の意を表した。

「ええと…運輸局の刑事さんたちには本当に感謝しています。ただ…今回は復元作特別展ということで、盗まれたのもさほど価値のないレプリカで、処分にも手間がかかるのでもともと展覧会の終了後に抽選であげようと思っていたんです…だから、盗まれても別に困らなかったというか…」

「ああ、でも…運輸局にはとにかく感謝しています。仕事の効率はなかなかいいですからね。」

天網恢恢疎にして漏らさず。スネージナヤ皇立軌道運輸局の刑事たちによる迅速な行動は、たとえ出国後間もなく溶解してしまう真氷創造物であっても、そうなる前に取り戻すということを皆に証明したのである！
